# MIX Video Studio

ブラウザ完結の非線形動画エディタ（NLE）。`daw-studio` と連携してミックス音声や `.daw` を取り込めます。

## 起動

```bash
cd video-studio
npm install
npm run dev
```

http://localhost:1430 で開きます。

## UI の使い方

| モード | 説明 |
|--------|------|
| **かんたん**（初期） | ウェルカム画面・ガイドタブ・短いヒント。ミキサーはコンパクト表示。 |
| **詳細**（ヘッダー右上） | 映像FXタブ・リンク解除・トラック追加・やり込みヒントをすべて表示。 |

- 左 **ガイド** … 今やるべきこと（チェックリスト）
- 左 **メディア** … 素材の追加とタイムライン配置
- 右 **インスペクター** … クリップ / 映像FX / プロジェクト
- **?** キー … ショートカット一覧

## 主な機能

- **マルチトラック**: 映像×2、音声×2、テキスト、オーバーレイ（画像）
- **音声モデル（重要）**:
  - 動画を追加 → **Video トラック（映像のみ）** + **Audio トラック（動画から抽出・リンク同期）**
  - DAW `.daw` → **Audio 2（BGM/DAW）** に配置（動画の音とは別ソース）
  - クリップ単位の 🔊 ON/OFF、トラック M/S、マスター音量、プレビュー再生
- **インポート**: MP4/WebM、音声、画像、DAW `.daw`
- **編集**: 移動、トリム、分割、複製、速度、音量、不透明度、クロスフェード
- **波形**: 音声トラックに簡易波形表示
- **テキスト**: タイトル・サイズ・色
- **映像 FX**: 明るさ、コントラスト、彩度、ぼかし、グレースケール、セピア
- **書き出し**: **MP4**（YouTube 向け・H.264+AAC）または WebM。非対応ブラウザは自動で MP4 変換
- **保存**: `.vproj` JSON
- **ショートカット**: Space 再生、S 分割、M クリップ音声 ON/OFF、+/- ズーム、Delete 削除、Ctrl+Z/Y

## DAW 連携

1. `daw-studio` でミックスを書き出すか `.daw` を保存
2. Video Studio の「DAW」で `.daw` を読み込む → **Audio 2（BGM/DAW）** に配置（緑の DAW クリップ）
3. 動画をインポート → 元動画の音は **Audio 1（動画から抽出）**、DAW ミックスはその上に重ねる
4. タイムラインで位置合わせ → WebM 書き出し（映像＋全音声ミックス）
